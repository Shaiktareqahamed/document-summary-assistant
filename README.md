# Nexus AI - Document Summary Assistant

Enterprise-grade document intelligence application that extracts and synthesizes data from uploaded files.

**Live Demo:** [https://document-summary-assistant-kappa.vercel.app/](https://document-summary-assistant-kappa.vercel.app/)

## Features
- **Document Upload:** Drag-and-drop interface for PDF, Image (PNG/JPG), and TXT files.
- **Text Extraction:** Native TXT parsing, PDF parsing via `pdfjs-dist`, and Optical Character Recognition (OCR) via `tesseract.js`.
- **AI Summarization:** Length-adjustable smart summaries (Short, Medium, Long) powered by Google Gemini AI.
- **Modern UI:** Responsive, animated interface built with Tailwind CSS.

## Tech Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Google Gemini API
- pdfjs-dist
- tesseract.js
